# Codex-VPN — Privacy Policy

Public legal pages for the **Codex-VPN** mobile application, served with
GitHub Pages (free).

## Live URLs

- Privacy Policy: https://codex-zubair.github.io/vpn_privacy_policy/privacy.html
- Landing page:  https://codex-zubair.github.io/vpn_privacy_policy/

## Structure

- `docs/privacy.html` — the full privacy policy (self-contained, responsive).
- `docs/index.html` — small landing page linking to the policy.

## Publishing (GitHub Pages)

Repository **Settings → Pages → Build and deployment**:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/docs`
- Save. The site goes live in ~1–2 minutes.

## Updating the policy

1. Edit `docs/privacy.html`.
2. Update the "Last updated" date.
3. Commit and push to `main`.

The in-app copy of the policy is kept in sync manually in the
`vpn_app_flutter` project (`lib/screens/privacy_policy_text_screen.dart`).
